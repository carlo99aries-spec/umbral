# Code of Conduct

## The short version

Be decent. Argue about the algorithm, never about the person.

## Expected

- Critique ideas with evidence: a test, a spec, a source.
- Assume good faith, especially with newcomers and with AI-assisted contributions.
- Respect that this project is a critique of coercive scoring — using it to harass contributors is a contradiction.
- Disagree publicly, resolve privately, and accept a maintainer's decision on scope.

## Unacceptable

- Harassment, threats, or targeted pile-ons.
- Discriminatory language about identity, background, or ability.
- Publishing someone's private information.
- Using the project — or its issue tracker — to score, rank, or shame real people.
- Sustained disruption of discussions.

## Enforcement

Reports go to the maintainer via a private GitHub advisory or by opening an issue titled `[CONDUCT] contact request` (no details in the issue).

Responses escalate: a private warning → temporary restriction from the repository → permanent ban. The maintainer will explain the decision to the person affected. There is no appeals committee on a project this size; there is a person who will read what you say.

## Scope

Applies to issues, PRs, discussions, commit messages, and anywhere you represent the project.
